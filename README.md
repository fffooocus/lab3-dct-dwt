**Реалізація алгоритмів стиснення з втратами**

Левківський Євгеній Сергійович · ІПС-41

[Відкрити програму](https://levkivskyi-lab3-dct-dwt.pages.dev/) · [Звіт PDF](https://levkivskyi-lab3-dct-dwt.pages.dev/docs/report.pdf) · [Завантажити весь проєкт](https://github.com/fffooocus/lab3-dct-dwt/archive/refs/heads/main.zip)

Браузерна програма для експериментального порівняння **Original | DCT | DWT**. Власне матричне DCT у блоках 8×8, багаторівневе DWT Хаара, зміна частки коефіцієнтів, PSNR, графік, експорт PNG та CSV. Готових функцій перетворень і залежностей для запуску немає.

## Запуск

Відкрити **[index.html](index.html)** подвійним клацанням. Програма працює локально, включно із завантаженням власних зображень.

Або з Node.js 20+:

```sh
npm start
```

Адреса: http://127.0.0.1:4173. Через HTTP обчислення виконуються у Web Worker; при відкритті файлу — в основному потоці. Завантажені зображення обробляються у браузері.

## Умови порівняння

Для обох методів вхідні пікселі центруються відніманням 128. Кольорові фото переводяться в яскравість `Y = round(0.299R + 0.587G + 0.114B)`; прозорість накладається на біле тло. При перевищенні обраної максимальної сторони фото зменшується зі збереженням пропорцій.

DCT: `A = C B Cᵀ`, обернення: `B = Cᵀ A C`, де `C` — власноруч побудована ортонормована матриця DCT-II 8×8. DWT Хаара: попарні суми та різниці, поділені на `√2`, спочатку за рядками, потім за стовпцями, рекурсивно в LL. Обернення виконує протилежний порядок.

Обидва масиви доповнюються крайовими пікселями до кратності `max(8, 2^L)`. Глобально вибираються **рівно** `K = round(N × p / 100)` найбільших за модулем коефіцієнтів окремо для кожного методу. Решта обнуляється. При однакових модулях перевагу має менший індекс. Значущі коефіцієнти (`|c| > 1e-9`) рахуються окремо від вибраних позицій.

Після відновлення додається 128, доповнення обрізається, пікселі округлюються та обмежуються до `[0, 255]`. PSNR рахується для цих 8-бітних пікселів у початкових розмірах:

```text
MSE = sum((original - restored)^2) / (width × height)
PSNR = 10 × log10(255^2 / MSE)
MSE = 0 → PSNR = ∞
```

**Частка коефіцієнтів не є розміром закодованого файлу.** Ентропійне кодування та власний бітовий формат не реалізовані. `N/K` описує лише скорочення кількості вибраних позицій. PNG слугує для експорту результатів.

Вбудовані зразки синтетичні й детерміновані; їх генерує [js/samples.js](js/samples.js). Зовнішні зображення для повторення експериментів не потрібні. Стандартні експерименти: 512×512, 3 рівні Хаара, 5%, 15%, 35% збереження.

## Перевірка та відтворення

```sh
npm test
npm run experiments
npm run build
```

12 математичних тестів перевіряють також DCT за незалежною прямою формулою, енергію перетворень, приклад Хаара 2×2, багаторівневе обернення, точне K, PSNR і повне відновлення з доповненням. Результати з нескінченним PSNR записуються в JSON рядком `"Infinity"`, у CSV — `Infinity`.

Для повторного створення PDF та автоматичної перевірки інтерфейсу потрібен лише додатковий інструмент Playwright:

```sh
npm install --no-save playwright
npx playwright install chromium
npm run documents
# В іншому терміналі має працювати npm start:
node scripts/browser-check.cjs
```

`npm run documents` оновлює PDF, DOCX, HTML та Markdown з фактичних результатів `results/experiments.json`. Скриншоти перевірки потрапляють у `.artifacts/`.

## Публікація

`npm run build` копіює програму, звіт та результати до `dist/`. Папка придатна для Cloudflare Pages та іншого статичного хостингу. Конфігурація Pages — [wrangler.jsonc](wrangler.jsonc). Секрети й облікові дані в репозиторії відсутні.
